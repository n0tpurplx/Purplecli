01. THE IDEA

The PURPLE ACTION LICENSE, abbreviated as PAL, is a reusable software license designed to allow software to be used, modified, forked, contributed to, incorporated into other projects, and used commercially while preserving the identity and origin of the original work.

In simple terms:

Use it. Fork it. Modify it. Build with it. Make money with it. Just don’t pretend you created the original.

Attribution must, where reasonably possible:

1. Identify the original work.
2. Identify the original copyright holder.
3. State that the distributed work contains or is derived from the original work.
4. Provide a link to the original project or source repository when the distribution format allows links.

Recommended attribution

06. FORKS

Forking is explicitly permitted.

You may create a fork, rename it, redesign it, modify it, expand it, or otherwise develop it into a separate project.

However, a fork must not falsely present itself as the original project.

A distributed fork must make it reasonably clear that it is a fork or derivative of the original work.

Acceptable examples include:

A fork of [PROJECT NAME]

Based on [PROJECT NAME]

Derived from [PROJECT NAME]

You may give your fork its own name and branding, provided that doing so does not falsely imply that it is the original or officially maintained project.
